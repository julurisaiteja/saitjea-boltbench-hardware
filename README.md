# Boltbench

Tools and hardware for people who actually build.

**Style:** Utilitarian Industrial  
**Diamond batch:** 4 (#38)  

## Run locally

```bash
npm i
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Production build:

```bash
npm run build
npm start
```

## Features

- Homepage film (autoplay muted loop + poster fallback)
- AI assistant with niche Q&A
- Offers / coupon `BENCH10`
- Reviews, deep catalog (search/filter/sort), PDP specs & FAQ
- Cart → Stripe-style checkout → success
- Niche desk: `/projects` (Projects)
- Locations, journal, account/loyalty teaser, newsletter
- Soft motion + reduced-motion respect
